# CustomsGuardian AI

An AI-powered Customs Documentation Validation System that automatically validates import/export documents and detects mismatches across Commercial Invoices, Packing Lists, Certificates of Origin, Bills of Lading, and more.

## Features

- 📄 **Multi-Document Upload** — Drag & drop PDF, PNG, JPG support
- 🔍 **OCR + AI Extraction** — pdf-parse for text PDFs, Tesseract.js for scanned images
- 🤖 **Gemini 2.5 Flash** — Semantic LLM extraction, works on ANY document layout
- ✅ **Validation Engine** — Cross-document field comparison
- ⚠️ **Mismatch Detection** — Quantity, weight, HS code, price, country mismatches
- 📊 **Risk Scoring** — Animated gauge with Low/Medium/High/Critical levels
- 📝 **AI Summary** — Professional narrative report generated by Gemini
- 📥 **PDF Report** — Downloadable validation report with all findings
- 🌙 **Dark Glassmorphism UI** — Premium enterprise design

## Prerequisites

- Node.js v18+
- Google Gemini API Key ([Get one here](https://aistudio.google.com/))

## Setup

### 1. Clone & configure environment

```bash
# Copy environment template
cp .env.example backend/.env

# Edit backend/.env and add your Gemini API key
GEMINI_API_KEY=your_actual_api_key_here
```

### 2. Install & run backend

```bash
cd backend
npm install
npm run dev
```

Backend runs on http://localhost:5000

### 3. Install & run frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on http://localhost:5173

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/upload` | Upload documents |
| POST | `/api/extract` | OCR + AI extraction |
| POST | `/api/compare` | Validation + mismatch detection |
| POST | `/api/report` | Generate PDF report |
| GET | `/api/history` | Session history |
